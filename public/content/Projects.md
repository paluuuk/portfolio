## Exoskeleton Terrain Perception
Developed a real-time computer-vision pipeline for lower-limb exoskeleton terrain perception using stereo depth sensing, 3D point-cloud processing, and CNN-based classification. The system recognizes seven terrain classes and was designed to support terrain-aware gait adaptation. I explored ZED neural depth, confidence filtering, region-of-interest processing, Navier–Stokes inpainting, denoising, temporal filtering, IMU-based orientation compensation, and compact point-cloud representations to improve robustness under glare, reflections, missing depth, and changing outdoor lighting. The classifier achieved approximately 95% accuracy during project evaluation.

## Beehive

The product combines Firebase-backed authentication and data services with real-time chat, push notifications, bookmarks, and location functionality, and has scaled to more than 1,000 active users across iOS and Android.

## Aerial Road Segmentation
Built an end-to-end semantic-segmentation workflow for extracting road networks from aerial imagery using a U-Net architecture in PyTorch. The project includes image/mask preprocessing, augmentation, a custom dataset and data-loader pipeline, hybrid Dice and binary cross-entropy loss, training and validation loops, checkpointing, and inference visualization on the Massachusetts Roads Dataset.

## SenSync
Developed a cross-platform Flutter prototype for predicting sensory overload in individuals with ASD from wearable physiological signals. The project combines mobile health-data workflows, Firebase services, location and notification features, and a Random Forest pipeline trained on the WESAD dataset. Individual data-collection and ML components were implemented as working prototypes, while the repository documents the remaining integration boundary between the mobile workflow and prediction service.
